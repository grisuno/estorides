Doctrine (inviolable)

The development cycle is non-negotiable:

  1. Spec — spec/<modulo>.md with Given-When-Then BDD scenarios.
  2. Test (red) — tests/test_<modulo>.py must fail.
  3. Code (green) — minimum to pass.
  4. Refactor — boy-scout: dedupe, harden, simplify. Out-of-scope fixes are still in-scope.
  5. Validation — pytest + ruff + mypy --strict + bandit.
  6. Fuzzing — hypothesis property-based, ≥ 1000 examples/invariant.
  7. Documentation — update spec, CLAUDE.md, README, this home page. After validation.

Read the full doctrine in CLAUDE.md.
